# At-risk marine species range shifts and EEZs

This repo houses project code and data for investigating the species range shifts of IUCN listed AquaX marine species: [AquaX paper](https://doi.org/10.1371/journal.pone.0335823).

## Repo structure
* data - project data
* data_explore - preliminary exploration 
* data_mgmt - downloading and preparing data
* figures - exploratory and final figures
* sample - a subsample of about 500 species
* scripts - main scripts in numerical order
